# Experiment: LEX Program to Convert the Substring "abc" to "ABC"

## Aim

To implement a LEX program to convert every occurrence of the substring "abc" into "ABC" in the given input string.

## Algorithm

1. Start the program.
2. Read the input string using the LEX scanner.
3. Match the alphabetic characters from the input.
4. Traverse the matched string character by character.
5. Check whether the current position contains the substring "abc".
6. If found, replace "abc" with "ABC".
7. Continue scanning until the end of the string.
8. Display the modified string.
9. Stop the program.

## Expected Output

```
Enter the string:
abc hello xabc yzabc

ABC hello xABC yzABC
```

## Result

The LEX program was executed successfully and all occurrences of the substring "abc" were converted to "ABC".
